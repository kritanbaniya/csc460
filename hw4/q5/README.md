# HW4 Q5 – Exploratory Data Analysis: U.S. College Costs and Earnings

`eda.ipynb` is an exploratory data analysis of `institutions.csv` (3,392 U.S. colleges, 12 columns) from the
[College ROI Dataset](https://github.com/thomasthinks/college-roi-data). That dataset is listed in the Education section of
[awesome-public-datasets](https://github.com/awesomedata/awesome-public-datasets#education).

## Run
```
pip install pandas numpy matplotlib seaborn jupyter
jupyter notebook eda.ipynb
```
